# FTP上传/下载稳定性测试

## 项目说明

本项目用于测试FTP服务器的上传和下载稳定性，通过循环测试来评估FTP传输性能。

## 文件结构

```
ls8_up_load/
├── config.ini      # 配置文件
├── main.py         # 主程序入口
├── utils.py        # 工具模块
└── requirements.txt # 依赖说明
```

## 运行方式

```bash
cd d:\Hcode\ls8_up_load
python main.py
```

---

## 逻辑流程详解

### 1. 启动流程

```
运行 main.py
    ↓
显示测试类型选择菜单
    ├── 输入 1 → 上传速率测试
    └── 输入 2 → 下载速率测试
    ↓
加载配置文件 config.ini
```

### 2. 初始化阶段

```
2.1 读取配置
    ├── FTP服务器配置 (IP/端口/账号/密码)
    ├── 测试参数 (循环次数/文件大小/间隔时间)
    └── 输出配置 (路径/文件名)

2.2 创建输出目录
    ├── ls8_up_load_up_csv/     # 上传CSV报告目录 (下载时为 down)
    ├── ls8_up_load_up_log/    # 上传日志文件目录 (下载时为 down)
    └── ls8_up_load_up_download/ # 上传下载临时文件目录 (下载时为 down)

2.3 初始化日志
    └── 创建日志文件: YYYYMMDD_XX_项目名_log.txt

2.4 初始化CSV报告
    └── 创建CSV文件: YYYYMMDD_XX.csv
```

### 3. 测试执行流程 (循环)

#### 3.1 上传测试流程 (test_type = 1)

```
第N次循环开始
    │
    ├─▶ 建立FTP连接
    │       ├── 连接FTP服务器
    │       ├── 登录认证
    │       └── 设置传输模式
    │
    ├─▶ 上传测试文件
    │       ├── 读取本地测试文件 (D:\Hcode\500mb_test_file.dat)
    │       ├── 使用STOR命令上传到FTP服务器
    │       └── 使用1MB缓冲区块传输
    │
    ├─▶ 记录结果
    │       ├── 计算传输耗时
    │       ├── 计算传输速率 (MB/s)
    │       └── 写入CSV
    │
    ├─▶ 清理远程文件
    │       └── 删除FTP服务器上的测试文件
    │
    └─▶ 关闭FTP连接
            └── 等待间隔时间后进入下一次循环
```

#### 3.2 下载测试流程 (test_type = 2)

```
第N次循环开始
    │
    ├─▶ 建立FTP连接
    │       ├── 连接FTP服务器
    │       ├── 登录认证
    │       └── 设置传输模式
    │
    ├─▶ 检查测试文件是否存在
    │       ├── 存在 → 直接下载
    │       └── 不存在 → 先上传再下载
    │
    ├─▶ 下载测试文件
    │       ├── 使用RETR命令从FTP服务器下载
    │       ├── 保存到临时目录
    │       └── 使用1MB缓冲区块传输
    │
    ├─▶ 记录结果
    │       ├── 计算传输耗时
    │       ├── 计算传输速率 (MB/s)
    │       └── 写入CSV
    │
    ├─▶ 清理临时文件
    │       └── 删除本地临时下载文件
    │
    └─▶ 关闭FTP连接
            └── 等待间隔时间后进入下一次循环
```

### 4. 结果输出流程

```
所有循环完成后
    │
    ├─▶ 统计汇总
    │       ├── 总测试次数
    │       ├── 成功/失败次数
    │       ├── 成功率
    │       └── 速率统计
    │           ├── 平均速率
    │           ├── 标准差
    │           ├── 最大速率
    │           ├── 最小速率
    │           └── 波动百分比
    │
    ├─▶ 输出到CSV
    │       └── 在CSV末尾写入汇总统计
    │
    ├─▶ 输出到控制台
    │       └── 打印完整统计信息
    │
    └─▶ 写入日志
            └── 记录测试完成信息
```

## 关键特性

1. **使用已有测试文件**: 不再每次生成500MB文件，读取指定路径的测试文件
2. **支持上传/下载**: 用户运行时选择测试类型
3. **自动文件检查**: 下载测试时自动检查FTP服务器上是否存在文件
4. **自动清理**: 上传后删除远程文件，下载后删除本地临时文件
5. **完善异常处理**: 捕获各种FTP错误和网络异常
6. **分块传输**: 使用1MB缓冲区，避免内存溢出
7. **统计全面**: 计算平均速率、标准差、最大最小值、波动百分比
