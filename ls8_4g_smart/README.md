# 4G拨号连接测试

## 项目说明

本项目用于测试接收机4G拨号连接的稳定性，通过SSH远程执行拨号脚本、查看日志和Ping测试来验证4G网络连接是否正常。

## 文件结构

```
ls8_4g_smart/
├── config.ini      # 配置文件
├── main.py         # 主程序入口
├── utils.py        # 工具模块
└── requirements.txt # 依赖说明
```

## 运行方式

```bash
cd d:\Hcode\ls8_4g_smart
pip install -r requirements.txt
python main.py
```

## 逻辑流程详解

### 1. 启动流程

```
运行 main.py
    ↓
加载配置文件 config.ini
    ├── SSH服务器配置 (IP/端口/账号/密码)
    ├── 测试参数 (循环次数/脚本路径/日志文件)
    └── 输出配置 (路径/文件名)
    ↓
创建输出目录
    ├── ls8_4g_smart_csv/   # CSV报告目录
    └── ls8_4g_smart_log/   # 日志文件目录
```

### 2. 测试执行流程 (循环)

```
第N次循环开始
    │
    ├─▶ SSH连接接收机
    │       ├── 建立SSH连接
    │       └── 验证连接状态
    │
    ├─▶ 修改脚本权限
    │       └── chmod +x /data/sbin/start_4g.sh
    │
    ├─▶ 执行4G拨号脚本
    │       ├── cd /data/sbin
    │       └── ./start_4g.sh
    │
    ├─▶ 查看日志文件
    │       ├── cat /log/4g.log
    │       └── 提取最后4行日志
    │
    ├─▶ 执行Ping测试
    │       └── ping www.baidu.com -c 4
    │
    ├─▶ 记录结果
    │       ├── 写入CSV
    │       └── 记录日志
    │
    └─▶ 关闭SSH连接
            └── 等待3秒后进入下一次循环
```

### 3. 结果输出流程

```
所有循环完成后
    │
    ├─▶ 统计汇总
    │       ├── 总测试次数
    │       ├── 成功/失败次数
    │       └── 成功率
    │
    ├─▶ 输出到CSV
    │       └── 在CSV末尾写入汇总统计
    │
    ├─▶ 输出到控制台
    │       └── 打印完整统计信息
    │
    └─▶ 写入日志
            └── 记录测试完成信息
```

## 测试步骤说明

### 步骤1: SSH连接
- 连接到接收机 (192.168.1.1)
- 使用账号: root，密码: huacenav
- 连接超时: 30秒

### 步骤2: 修改权限
- 执行命令: `chmod +x /data/sbin/start_4g.sh`
- 确保脚本可执行

### 步骤3: 执行拨号
- 进入目录: `cd /data/sbin`
- 执行脚本: `./start_4g.sh`
- 等待脚本执行完成

### 步骤4: 查看日志
- 读取日志: `cat /log/4g.log`
- 提取最后4行日志
- 输出到控制台和日志文件

### 步骤5: Ping测试
- 执行命令: `ping www.baidu.com -c 4 -W 10`
- 检查是否能正常访问互联网
- 记录测试结果

## 常见问题

### Q1: SSH连接失败
**A:** 检查以下内容：
1. 接收机IP地址是否正确
2. 网络是否连通
3. 账号密码是否正确
4. SSH服务是否启动

### Q2: 脚本执行失败
**A:** 检查以下内容：
1. 脚本路径是否正确
2. 脚本是否有执行权限
3. 脚本内容是否有语法错误
4. 查看日志文件了解详细错误信息

### Q3: Ping测试失败
**A:** 检查以下内容：
1. 4G模块是否正常工作
2. 网络信号是否良好
3. DNS配置是否正确
4. 查看日志文件了解详细错误信息

### Q4: 如何修改测试参数
**A:** 编辑 `config.ini` 文件，修改对应参数：
- 修改循环次数: `cycle_times = 100`
- 修改Ping地址: `ping_address = www.google.com`
- 修改日志行数: `log_lines = 10`
